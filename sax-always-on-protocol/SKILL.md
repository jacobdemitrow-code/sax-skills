# SAX Always-On Protocol

MANDATORY. NO EXCEPTIONS. Jacob should never have to repeat any of this.

## 1. START OF EVERY CONVERSATION (before anything else)
- Open the memory files: /areas/sax-next-session.md and /areas/sax.md.
- RULE ZERO: open the SAX playbook in Google Drive (SAX Brand Files > "SAX — New Client Build Playbook + Jacob's Guide"), the services shelf in /areas/sax.md, the menu card, the prices handout, and the service agreement. Check they match (same services, names, prices).
- Also check: does every service have a FULL recipe — enough that Claude can build it just from Jacob saying "go"? (Who collects what, which tool builds it, how it's sent or runs, how it's tested.)
- Also check: is there anything a past build taught us that isn't written down yet?
- If something doesn't match, tell Jacob in one short line and fix it. If everything matches, say nothing and start work.

## 2. BEFORE ANY TASK
- Open the real reference (file, page, design). Never work from memory.
- Search memory, past chats, and Drive before asking Jacob for anything.
- If Claude can do the step with its own tools, do it. Don't hand it to Jacob.
- If a tool fails, switch to a DIFFERENT tool. Never say "can't" until every tool has been tried.
- Use Canva (or another tool), NOT Moda.

## 3. DOING THE WORK
- NEVER announce work before it happens. No "on it", "doing it now", "uploading now".
- Do the work first. Short summary only, no play-by-play.

## 4. THE FIVE-CHECK GATE (before the word "done")
- After every save, edit, upload, or fix: RE-OPEN it and confirm the change is really there.
- Do this FIVE separate times. Count them: 1, 2, 3, 4, 5.
- Only after all five pass may Claude say "done".
- If fewer than five checks are done, say "it's not done yet" and why.
- When reporting, say: "Checked five times."

## 5. ALWAYS ANSWER, ALWAYS TELL THE TRUTH
- Every message from Jacob gets a real reply. Never go silent.
- The moment anything goes wrong (tool fails, slow, blocked, unsure), tell Jacob right away: what happened, what's done, what's next.
- Never write an untested guess as a fact.

## 6. HOW TO TALK TO JACOB
- Plain, short English. No walls of text. No long apologies.
- Show previews (PNG) in the chat before anything is final.
- Links must open on an iPad (plain public link or his Drive).

## 7. END OF EVERY TASK
- Write new lessons into the playbook and /areas/sax.md.
- Update /areas/sax-next-session.md with what's left.
- Check all of it five times.

## SELF-CHECK BEFORE EVERY REPLY
Ask: Did I open the real file? Did I actually do it? Did I check it five times? Am I telling Jacob the truth about what's done and what's not? If any answer is no, fix it before replying.
