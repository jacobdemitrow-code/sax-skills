# The 5-Check Gate

Re-opening the same file five times gives the same answer five times. Five DIFFERENT checks are what catch real mistakes.
Pick the row that matches the work, run all 5, then report.

## Pick the type of work

### A web page or site (link page, booking form, calculator, leads page)
1. **Source:** every name, price, phone, and link matches the source it came from.
2. **Logged-out:** the link opens in a fresh browser that isn't logged in.
3. **Phone:** it fits a phone-sized screen and every button works (tap or screenshot at phone size).
4. **Real test:** send one test booking, run one real price, or tap one Call/Text button. Confirm the result arrives or saves after a refresh.
5. **Privacy:** no customer names, numbers, or addresses are visible without a lock.

### A graphic (price menu, QR post, flyer)
1. **Source:** every price and phone number matches the client's price list, letter for letter.
2. **Readable:** viewed at phone size, all the text is big enough to read.
3. **Brand:** the client's colors and logo are correct, with no leftover template text. On SAX's own pieces, "StratAI Apex" sits small under every SAX logo (sax-core section 6).
4. **Works:** a QR code scans with a phone and opens the right page. Phone numbers and links are correct.
5. **Link:** the exported PNG opens from a plain public link on an iPad.

### A document (Google Doc, caption, playbook edit, skill edit)
1. **Saved:** re-open the file and confirm the change is really there.
2. **Source:** every name, price, and link matches the real source (copied, not typed from memory).
3. **Nothing broken:** the rest of the file still reads right, with no deleted or doubled sections.
4. **Everywhere:** if the change affects prices or services, the other SAX files agree (see sax-core section 4).
5. **Link:** it opens on an iPad with no login wall.

### A text message or message template
1. **Facts:** business name, offer, link, and phone are correct.
2. **Length:** under the limit the recipe gives (usually 300 characters).
3. **Voice:** it sounds like the client or Jacob, with no salesy words.
4. **Rules:** it includes "Reply STOP to opt out" when it goes to customers, and it only goes to people who did business with the client.
5. **Prefill:** if it's on a Text button, tap it on a phone and confirm the message fills in correctly.

### A quote or a price math answer
1. **Price list:** every line price matches the price list.
2. **Math, way 1:** add the lines top to bottom.
3. **Math, way 2:** add them again in a different order. Both totals must match.
4. **Rules:** minimums, "see it first" jobs, and extra bathrooms are applied.
5. **Message:** the customer message shows the same total.

### A lead list
1. **Real:** each business was found on a real listing or site (no made-up businesses).
2. **Phones:** local numbers only. No toll-free numbers (800, 833, 844, 855, 866, 877, 888).
3. **No guesses:** every email was actually seen published. Blank is better than guessed.
4. **No repeats:** no duplicate names or phone numbers, and nobody already on the client's page.
5. **In the area:** every business is inside the area asked for, and no national chains.

## How to report (always this format)
"**Checked 5 of 5:** source ✓, logged-out ✓, phone ✓, test booking arrived ✓, privacy ✓."

If any check didn't pass or couldn't be run:
"**Checked 3 of 5.** Not checked: phone test (no phone-size view in voice) and test booking (form not live yet). **Not done yet.**"

Rules:
- Never round up. 4 of 5 is "not done yet."
- Name every check that was skipped, and why.
- If a check fails, fix it, then run all 5 again.
- If Jacob asks "did you check it?", give the honest number first.
