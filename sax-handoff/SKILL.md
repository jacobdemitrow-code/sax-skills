# SAX Handoff

Goal: the next chat starts fresh and knows only what it needs. Short beats complete.

## When to offer it (one line, don't push)
- Jacob corrected the same thing twice.
- You notice rules or facts being repeated.
- The task changes, or the chat is very long.
Say: "This chat is getting long. Want me to write a handoff and start fresh?"

## Write the doc
Google Drive, folder `1D8QZ-NXLnRVx6IheIf4vByR-XDZkRV_2` (where the other "SAX — Next Session" docs live).
Title: `SAX — Next Session (Mon DD)` with today's date. If one exists for today, add the new handoff at the TOP of it, above a line `----------`. Never delete older notes.

Use exactly these sections. Under 1 page. Only facts confirmed in this chat. Mark anything unsure as UNVERIFIED.

1. **COPY-PASTE PROMPT** (first, so Jacob sees it on the iPad): "Read my sax-core skill, then the Drive doc '<this doc title>' (top section first). <the goal in one line>. <next step in one line>."
2. **GOAL**: what Jacob wants, in his words, 1–3 lines.
3. **DONE**: what is finished and checked (with real check counts).
4. **DECIDED**: choices Jacob made and why, so the next chat doesn't re-ask.
5. **NOT DONE / FAILED**: what broke or was skipped, and why.
6. **NEXT**: 1–3 steps, one at a time. Mark which ones need Jacob's OK.
7. **WHERE THINGS ARE**: links and IDs (Drive docs, Notion pages, sheets, scheduled task names). Never paste keys, passwords or the Send-all key.

## Then
- Re-open the doc and confirm it saved (sax-done-check, document row).
- Give Jacob the doc link and one line: "Open a new chat and paste the prompt at the top."
- Nothing else. No summary wall in chat.
